# UI Slice 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Account sheet for language + sign out, Spinner/EmptyState/SegmentedControl, and every remaining screen on the shared `ui/` components — with no behaviour change.

**Architecture:** Three new presentational components in `web/src/ui/`; a new `components/AccountSheet.tsx` opened from Shell's header; then mechanical migration of screens in three batches following one rulebook (Global Constraints).

**Tech Stack:** React 19, react-router 7, react-i18next, Tailwind 4.3 (`@theme` tokens), Vitest 5 + Testing Library + jsdom, TypeScript 7.

**Spec:** `docs/superpowers/specs/2026-09-29-ui-slice3-design.md`

## Global Constraints

- Work in `web/`. Focused tests: `npx vitest run <file>`. Before each commit: `npm test` and `npx tsc --noEmit` both clean.
- **No behaviour change.** Keep every condition, handler, prop, label text, `data-testid`, `aria-*` and heading level.
- Existing tests must pass without edits, except a selector-only edit forced by a deliberate markup change; list each in the commit body.
- Existing shared components (do not change their APIs except as a task says):
  - `Button` (`web/src/ui/Button.tsx`): `variant` = `primary | secondary | danger | ghost | warn`, `size` = `md | lg`, native props + `ref` pass through, `type` defaults to `"button"`.
  - `Card({ title?, className?, children })` — `<section>`, title renders `<h2>`.
  - `Banner({ tone: "error"|"warn"|"info"|"success", action?, className?, children })` — error is `role="alert"`, others `role="status"`.
  - `Field({ label, hint?, error?, children: ({id, describedBy}) => node })`.
  - `Dialog({ label, onClose, className?, children, initialFocusRef? })` — `role="dialog"` `aria-modal` `aria-label`; Escape and backdrop tap call `onClose`; focus returns on unmount.
- Tokens: `bg-brand`, `text-brand-strong`, `border-brand`, `bg-surface`, `bg-canvas`, `text-ink`, `text-muted`, `text-danger`, `text-warn`.
- **Migration rulebook** (Tasks 3-5):
  1. Raw `<button>` -> `Button`. Variant: the screen's main action `primary`; other actions `secondary`; destructive (delete/void/discard/remove/close day) `danger`; inline link-like `ghost`. Keep all props. If an existing class did layout (`w-full`, `flex-1`, margins), pass it via `className`; drop only colour/border/radius/min-height classes the variant now provides.
  2. Error paragraphs (red) -> `Banner tone="error"`; amber warnings -> `tone="warn"`; neutral notices -> `tone="info"`; green confirmations -> `tone="success"`. Same text and children; keep any `data-testid` by moving it onto a wrapping element only if Banner does not accept it — Banner does not spread props, so put the testid on an inner `<span>` around the text.
  3. `border ... rounded-xl bg-white` panels -> `Card` (use `title` only where the panel's first child is an `<h2>`).
  4. Hand-rolled `role="dialog"` overlays -> `Dialog` with the same `label`. For irreversible confirms, create `const cancelRef = useRef<HTMLButtonElement>(null)`, put `ref={cancelRef}` on Cancel and pass `initialFocusRef={cancelRef}`. `onClose` = the existing cancel handler, guarded to a no-op while that screen's in-flight flag is true.
  5. Loading text paragraphs -> `<Spinner label={...} />` keeping any `data-testid` (Spinner passes extra props through). Empty-list paragraphs -> `<EmptyState>{same text}</EmptyState>`.
  6. Colours: `bg-emerald-600`/`bg-green-600` -> `bg-brand`; `text-emerald-700`/`text-green-700` -> `text-brand-strong`; `bg-white` on panels/inputs -> `bg-surface`.
  7. Do not touch: `.receipt-slip` print markup; chart/figure internals in Dashboards; any logic.
- Commit messages end with a blank line then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```tsx
import type { HTMLAttributes, ReactNode } from "react";

/** Something is on its way. The label is visible text, not just an aria-label: on a slow
 *  connection the words tell staff it is working, where a bare ring looks frozen. */
export function Spinner({ label, className = "", ...rest }:
  { label: ReactNode } & HTMLAttributes<HTMLDivElement>) {
  return (
    <div role="status" className={`flex items-center gap-2 text-sm text-muted py-2 ${className}`} {...rest}>
      <span aria-hidden="true"
            className="inline-block w-4 h-4 rounded-full border-2 border-slate-300 border-t-brand animate-spin" />
      {label}
    </div>
  );
}
```

Note: the ring has no text, so `textContent` equals the label (the test relies on it).

```tsx
import type { ReactNode } from "react";

export function SegmentedControl<T extends string>({ label, options, value, onChange }: {
  label: string; options: { value: T; label: ReactNode }[]; value: T; onChange: (v: T) => void;
}) {
  return (
    <div role="radiogroup" aria-label={label} className="flex rounded-lg border border-slate-300 bg-surface p-0.5 gap-0.5">
      {options.map((o) => {
        const on = o.value === value;
        return (
          <button key={o.value} type="button" role="radio" aria-checked={on} onClick={() => onChange(o.value)}
                  className={`flex-1 min-h-[44px] px-2 rounded-md text-sm ${
                    on ? "bg-brand text-white font-semibold" : "text-ink active:bg-slate-100"}`}>
            {o.label}
          </button>
        );
      })}
    </div>
  );
}
```
